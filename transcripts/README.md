# Lesson transcripts (word-for-word)

Full, verbatim transcripts of Chris Roe's elk vocalization & communication
lessons, kept here as a **just-in-case reference**.

These are intentionally **not shown in the website UI** — the app displays a
distilled, reworded "Full breakdown" for each call instead (the `lesson` field
in `../data.js`). This folder is the raw source of record.

> These are auto-generated transcripts, so expect mis-hears. The recurring ones:
> **mew** → "mu / mue / mus / mute / muse / meow"; **whine** → "wine / wind";
> **estrus** → "Esther's / espresso"; **lost** → "loss"; **reed** →
> "read / breath / reached out"; **Hyperlip** → "hyperlap / hyperloop";
> **Hoochie Mama** → "Fujimama / Uchimama"; **assembly** → "semblante";
> **Roe Hunting Resources** → "Rowani Resources"; and the name itself →
> "Rowe" (it's Chris **Roe**). Each file lists its own quirks up top.
